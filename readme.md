# Daily Code Challenges 🚀

A collection of small JavaScript problems and coding exercises that I solve regularly to improve my problem-solving skills, JavaScript fundamentals, and coding consistency.

## 🎯 Goal

The main goal of this repository is to:

- Improve JavaScript fundamentals
- Strengthen problem-solving skills
- Practice writing clean and readable code
- Learn different JavaScript methods and concepts
- Build a consistent daily coding habit
- Keep track of my coding progress

- Objects
- Functions
- Loops
- Conditionals
- Array Methods
- Object Methods
- ES6+ Features
- DOM Manipulation
- Async JavaScript
- Problem Solving
- And more...
